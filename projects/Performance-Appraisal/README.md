# Performance Appraisal System Analysis

## Project Overview
A study on the effectiveness of the performance appraisal system at Bhargave Rubber Pvt. Ltd., Madurai.

## Objective
To understand employees' perceptions of the performance appraisal system and identify areas for improvement.

## Tools Used
- Microsoft Excel
- Power BI
- Statistical Analysis

## My Work
- Studied employee feedback regarding the performance appraisal system.
- Analyzed employee satisfaction and perceptions.
- Created a dashboard to visualize the findings.
- Identified areas for improvement and provided recommendations.

## Key Findings
- Examined employee perceptions of the appraisal process.
- Studied the relationship between feedback and job performance.
- Identified areas where the appraisal system could be improved.

## Recommendations
- Establish a clear appraisal calendar.
- Communicate performance standards clearly.
- Strengthen feedback and follow-up processes.

## Outcome
The project helped me understand how employee feedback and data analysis can support HR decision-making and improve appraisal practices.
