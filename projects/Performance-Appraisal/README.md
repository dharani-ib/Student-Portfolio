# Performance Appraisal System Analysis

## Project Overview
A study on the effectiveness of the performance appraisal system at Bhargave Rubber Pvt. Ltd.

## Objective
To understand employees' perceptions of the performance appraisal system and identify areas for improvement.

## Tools Used
- Microsoft Excel
- Power BI
- Statistical Analysis

## My Work
- Collected and analyzed employee feedback.
- Studied employee satisfaction with the appraisal system.
- Created a dashboard to visualize findings.
- Identified areas for improvement and provided recommendations.

## Outcome
The project helped me understand how employee feedback and data analysis can support HR decision-making.
